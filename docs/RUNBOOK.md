# طريقة التشغيل

## المتطلبات

- Bun (أو Node 20+)

## محلياً

```bash
bun install
bun run dev      # http://localhost:8080
bun run build    # بناء الإنتاج
```

المفتاح `LOVABLE_API_KEY` مُهيّأ تلقائياً في بيئة Lovable ويُقرأ داخل
معالجات الخادم فقط.

## الاستخدام

1. افتح الصفحة الرئيسية `/`.
2. اضغط الكرة → اسمح بالميكروفون → تحدث.
3. اضغط الكرة مرة أخرى لإنهاء التسجيل؛ نيكو يفكر ثم يرد صوتياً.
4. `/dashboard` لعرض الذاكرة والمهارات والمهام.

> الميكروفون يتطلب HTTPS أو localhost. إن لم يتوفر ميكروفون، استخدم حقل
> الكتابة أسفل الصفحة — يمر بنفس مسار العقل ويرد صوتياً.

## خطة التطوير المستقبلية

**المرحلة 1 — الحسابات والمزامنة**
تفعيل Lovable Cloud: تسجيل دخول (بريد + Google)، جداول `profiles`,
`memories`, `conversations`, `tasks` مع RLS، ونقل `LongTermMemory` من
localStorage إلى محوّل قاعدة بيانات (نفس الواجهة).

**المرحلة 2 — ذاكرة دلالية**
تضمينات (embeddings) + بحث تشابه بدل مطابقة الكلمات، وتلخيص دوري للمحادثات
القديمة، ونظام تقادم/نسيان ذكي.

**المرحلة 3 — الصوت المستمر**
كلمة تنبيه ("يا نيكو")، كشف نشاط صوتي (VAD) للإرسال التلقائي، ونسخ لحظي
أثناء الكلام، ومقاطعة الرد.

**المرحلة 4 — سوق المهارات**
تحميل المهارات ديناميكياً، بيان صلاحيات لكل مهارة، وتنفيذ معزول (sandbox)،
ومهارات خارجية عبر الموصلات (تقويم Google، بريد، منزل ذكي حقيقي).

**المرحلة 5 — الموبايل**
React Native يستهلك نفس حزم `core/memory/skills` عبر monorepo، مع تنبيهات
خلفية وعمل بلا اتصال.

**المرحلة 6 — الإنتاج**
PostgreSQL، سجلات وتتبع للجودة، حدود استخدام، اختبارات آلية لمسار العقل،
ولوحة تحليلات للنوايا الأكثر تكراراً.
